# 7th_years_celebrity
PERSONAL PHOTOS. DO NOT COPY. ALL RIGHTS RESERVED.

Открытка-лендинг «7 лет вместе — 7 причин, почему я тебя люблю».

## Как посмотреть

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python -m http.server 8765
```

и зайти на http://localhost:8765 (с телефона в той же Wi‑Fi сети — по IP компьютера).

## Музыка

Положить трек в `assets/music/music.mp3`. Он начинает играть после нажатия на печать «7»
на заставке (телефоны не дают включать звук без нажатия). Кнопка в правом нижнем углу —
пауза / включить. Если файла нет, кнопка не появляется.

## Тексты и фото

- Тексты — прямо в `index.html`, каждая причина в своём блоке `<!-- Причина N -->`.
- Готовые кропы лежат в `assets/img/`, оригиналы — в `assets/`.
  Кадрирование настраивается в `tools/make_crops.py`, пересобрать: `python tools/make_crops.py` (нужен Pillow).
